💧 Controle de Níveis de Água

📌 Sobre o projeto

Este projeto consiste em um sistema simples desenvolvido em Python para monitorar os níveis de água de um reservatório por meio do terminal.

O programa utiliza a biblioteca Colorama para exibir mensagens coloridas de acordo com a situação identificada.

🎯 Objetivos

Armazenar cinco níveis de água em uma lista.

Criar uma função para definir a cor de cada nível.

Exibir mensagens de alerta coloridas.

Validar o nível informado pelo usuário.

Restaurar o estilo padrão do terminal após as mensagens.
